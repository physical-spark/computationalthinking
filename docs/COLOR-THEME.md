색상 값은 `web/src/style.css`의 역할별 변수에 모았다. SVG와 CodeMirror 구문 색상도 이 변수를 사용하며 별도의 어두운 테마를 불러오지 않는다. 강제 색상 모드의 시스템 색상 규칙은 유지한다.
