# 목차와 고정 하단 이동 검토 · 2026-10-17

범위: 학생의 전체 목차, 개념·영상·실습 이동, 실습 코드 패널. React·기존 CSS와 Physical Spark 색상 토큰을 유지한다. 별도 AGENTS.md·CONTRIBUTING.md·디자인 라이브러리는 없으며 기존 `docs/COLOR-THEME.md`, `docs/TEACHING-FLOW.md`를 따른다. `better-interface`가 지정한 여섯 스킬을 읽고 적용했다. 프로필·관리자 편집기는 변경 범위가 아니다.

장 목차 13개와 단원 69개는 접는 단계를 추가하지 않고 모두 제공한다. 현재 단원만 개념·영상·실습 목록을 보여 주는 기존 동작을 유지한다. 현재 단원에는 배경과 세로 표시, 현재 단계에는 배경·굵기·점을 사용하며 `aria-current`도 제공한다. 긴 영상 제목은 목차에서 반복하지 않고 영상 단계 본문에 표시한다. 관련 영상 묶음은 한 행으로 진입하고 이전·다음으로 한 편씩 본다.

개념 마지막 장에만 `코드 실습 시작 →`을 표시한다. 준비 장의 중복 실습 시작 버튼은 없앴다. 실습의 다음 버튼은 서버 저장된 통과 상태를 따르며 선택 Q&A는 조건이 아니다. 첫 실습 이전은 해당 단원의 마지막 개념/영상 장으로 돌아간다. 마지막 실습의 다음은 학습과정으로 간다. 학생 화면 미리보기의 읽기 전용 상태와 관리자 미리보기 동작은 유지한다.

원자료 `content/resources.json`의 50개 배치와 관리자 문구 블록은 보존한다. 학습 API는 첫 자료를 기준으로 같은 영상 ID를 하나로 묶고 원문 링크를 추가 출처로 연결한다. 구간은 합친다(전체 영상이 있으면 전체로). 삭제된 배치의 자료 ID는 별칭으로 유지하고 중복 개념 장 주소는 원래 영상으로 연결한다.

## 검증

- `uv run pytest -q`: 35건 통과. 원자료 50개에 대한 학생 API 46편·별칭 4개·옛 주소 연결 검사 포함.
- `uv run ruff check backend`, `npm run build --prefix web`: 통과.
- `npx playwright test tests/sidebar.spec.ts tests/navigation.spec.ts`: 7건 통과. 네 화면 크기의 목차와 세 화면 크기의 공통 하단 이동 검사.
- 기존 curriculum·teaching-flow·profiles-editor 검사도 실행한다. 변경된 영상 수와 마지막 장 실습 시작 흐름에 맞춰 기대값을 갱신했다.
- 하단 이동 검사에서는 실행 준비 메시지를 모의 처리하고 서버 저장된 합성 계정 통과 기록으로 이동을 확인한다. 실제 Python 실행·채점·입력·중지는 기존 실행 검사와 운영 확인에서 별도로 검증한다.
- CI 전체 검사와 운영 화면은 배포 후 Course Network Wiki의 별도 검증 기록에 남긴다.

미검증: 실제 iOS Safari 기기, VoiceOver 음성 출력, RTL 미러. 아주 짧은 데스크톱 화면, 긴 출력·디버거·오류 안내는 각 영역의 스크롤을 사용할 수 있다. 모든 길이의 코드를 무조건 스크롤 없이 표시한다고 보장하지 않는다.

판정: **Approve — 위 확인 범위에 한함.** 발견한 높은 우선순위의 접근성 오류는 수정하고 재검사했다.
