# 실습 2 · 생활 문제를 계산식으로 표현하기

2026-10-17 사용자 요청으로 `IntroducingTheShell.more_calculation`을 생활 문제로 재구성했다. 원래 Futurecoder 단계는 곱셈·나눗셈·뺄셈을 한 번 실행하는 탐색 과제였고 `5 - 6`도 통과했다. 새 과제는 일상의 조건을 골라 계산 순서와 괄호를 정하는 연습이다.

친구 4명이 영화표를 한 장씩 산다. 표는 한 장에 8,000원, 함께 먹을 팝콘 한 세트는 12,000원이다. 쿠폰 한 장으로 전체 금액에서 4,000원을 빼고 나머지를 4명이 똑같이 나눈다. 한 사람당 낼 돈을 Python 계산식 하나로 표현한다. 가격은 이 문제에서 정한 값이다.

가능한 식은 `(4 * 8000 + 12000 - 4000) / 4`이며 결과는 `10000.0`원이다. `8000 + (12000 - 4000) / 4` 같은 동등한 식도 인정한다. 숫자만 쓴 `10000`, 관계없는 `2 * 3`, 표를 한 장만 계산한 식, 할인 쿠폰을 네 번 뺀 식은 통과하지 않는다.

문제의 4, 8000, 12000, 4000을 모두 사용한다. 수량 1도 쓸 수 있다. 숫자·괄호·사칙연산·단항 부호로 된 표현식만 인정하며 변수·print·함수 호출은 이 과제의 범위가 아니다. 풀이 예시는 학생이 통과한 뒤 표시하고 관리자는 기존 정답 보기에서 확인할 수 있다. 세 가지 힌트와 영수증 모양 SVG를 제공한다. 출처는 자체 작성 문제와 Futurecoder 학습 흐름 참고를 구분한다. 숫자와 연산 기호는 관리자 문구 편집의 고정 코드 블록으로 보호한다.

`runtime/life_expression.py`가 문제·목표·예시·판정을 정의한다. 원본 upstream은 수정하지 않고 빌드와 네이티브 실행기/Pyodide 어댑터에 이 단계만 적용한다. Python 실행 오류를 통과로 덮어쓰지 않는다. 코드 실행과 통과 저장은 계속 서버가 소유한다. 런타임 판본에 새 채점 파일의 해시를 포함한다. 기존 단계 ID·주소·통과 기록은 보존하며 DB 마이그레이션은 없다.

함께 반영한 화면 수정:

- 실습 아래의 반복 영상 목록 제거. 영상은 앞선 개념·영상 단계와 목차에서 본다.
- 질문 대상은 멘토로 표시하며 실제 권한은 기존 관리자 역할을 유지한다.
- 복습·질문의 큰 흰 카드와 겹친 fieldset 테두리를 없앴다. 답변 선택 행과 textarea만 흰색으로 표시한다. 복습 제목은 하나로 줄인다.
- AI 요청문에는 문제·사고 목표·내 답변·현재 코드·실행 결과를 항상 포함한다. 포함 여부 체크박스를 제거했다. 자동 복사 실패 시 수동 복사 미리보기는 유지한다.

검증: 원전 285건의 회귀를 그대로 유지하고 실행 코어에서 새 문제 5건을 추가한다. 별도 단위 검사는 동등한 식 7개, 잘못된 식·답만 쓰기·변수/함수/문법 오류 14개, 다른 단계에 영향 없음과 기존 실행 오류 유지, 공개 콘텐츠의 문제·출처를 확인한다. 브라우저에서는 서버가 잘못된 두 제출을 거부하고 동등한 식의 통과 저장 후 다음 단계가 열리는지 확인한다. 요청문 클립보드와 복원 검사도 유지한다.

Jakub `better-layout`, `better-writing`을 적용했다. 복습·질문 영역의 정렬·문구·320/390/768/1440px·키보드 이름·axe를 확인한다. SVG는 300px 뷰박스로 구성하고 같은 내용의 본문과 접근성 설명을 제공한다. 실제 중학생의 난이도·학습 효과를 측정한 것은 아니다.
