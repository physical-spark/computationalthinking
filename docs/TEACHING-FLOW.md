# 강의 전체에 적용한 풀이·용어·영상 흐름

후속 변경: 학생에게는 중복 영상을 합친 46편을 보여 주고 개념 마지막 장에서 실습을 시작한다. 이전·다음은 공통 하단에 고정한다. 아래 50개 배치·준비 장의 실습 건너뛰기는 당시 구현 기록이며 현재 동작은 [목차와 고정 하단 이동](SIDEBAR-NAVIGATION.md)을 따른다.

2026-10-17 사용자 피드백에 따라 공통 학습 렌더러와 전체 개념 자료를 수정했다. 한 문장에 사과 봉지의 수량과 계산 순서를 압축하지 않고, 실제 코드에 나온 값을 그림으로 한 번씩 바꿔 보게 한다.

## 적용 범위

- 전체 69개 단원에서 같은 개념 페이지·작은 상단 메뉴·용어가 있는 목차·영상 단계 렌더러를 사용한다.
- 20개 개념에 62개 풀이 장면을 작성했다. 사과 계산, 글자 잇기, 변수, 반복, 조건, 인덱스, f 문자열, 중첩 반복, 함수, 논리, 게임판, 딕셔너리, 로그 처리와 모의 자동화까지 적용했다.
- 첫 `2 + 3 * 4`는 사과 세 개씩 네 묶음과 따로 두 개를 보여 준다. `3 * 4 = 12` 다음 `2 + 12 = 14` 순서이며 원래 코드·선택지·정답을 유지했다.
- 각 풀이 장면의 값·출력·반복 횟수·코드 줄 번호를 실제 Python 실행과 별도 에이전트 검토로 대조했다. 아동의 실제 독해·학습 효과를 측정한 것은 아니다.
- `변수`, `if 조건문`, `for 반복문`, `함수`, `인덱스`, `자료형` 등의 한국어 전문용어와 영어 이름을 13개 장·69개 단원 목차에 남겼다. 쉬운 제목도 유지한다.
- 상단의 별도 진도 줄을 없애고 진도를 메뉴 안에 합쳤다. 데스크톱 메뉴는 56px이며, 관리자 안내는 별도 28px이다. 44px 버튼 영역을 유지한다. 읽기 영역만 필요할 때 스크롤하고 이전·다음 버튼은 화면 아래에 유지한다.
- 기존 개념 페이지 1–6 주소를 유지하며, 관련 영상은 7번 이후에 한 편씩 붙인다. 영상이 있는 6번 준비 페이지에서도 바로 실습할 수 있다. 영상 시청은 통과 조건이 아니다.
- 영상은 선택된 페이지에서만 iframe 한 개로 불러오고 자동 재생하지 않는다. 46개 영상·50개 배치의 ID·원문·시작/끝 구간을 유지한다. 기존 `resource/<id>/1–3` 주소도 유지하고, 영상 목록의 링크는 재생 페이지 2번을 연다. 원본 링크와 관련 읽기 링크를 남긴다.
- 기존 문제 문구 15곳에서 실제 코드와 다른 설명과 긴 중첩 설명을 수정했다. 읽을거리 세 주제도 현재 과제에 맞췄다. 과제 ID·실습 순서·채점·진도는 바꾸지 않았다.

## 편집과 검증

관리자 편집기는 새 풀이의 용어·장면 제목·설명 문장을 편집한다. SVG 구조, 코드 줄 번호, 값, 결과는 웹 편집 대상에서 제외한다. 새 장면 문구는 일반 글자로 처리하며 HTML을 거부한다.

전체 코드 원전 회귀, 백엔드 권한·게시 검사, 320·390·768·1440px 화면과 200% 확대에 해당하는 720×402 유효 영역을 검사한다. 50개 영상 배치의 iframe ID·시간 범위·한 번에 한 개만 표시됨·자동 재생 꺼짐·새로고침 복원을 검사한다. CI에서는 외부 영상 서버를 모의 응답으로 대체하고 운영 Chrome의 플레이어 표시를 별도로 확인한다. CI 검사만으로 YouTube 영상 자체의 재생 가능 여부를 보장하지 않는다.

색상은 기존 Physical Spark 테마를 유지한다. 레이아웃 승인 범위는 위 화면 크기와 페이지 이동이며 RTL 미러는 검증하지 않았다. 실제 아동 이해도와 외부 영상의 향후 상태도 검증 범위 밖이다.
